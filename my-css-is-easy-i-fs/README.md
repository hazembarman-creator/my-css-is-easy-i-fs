## Description
This project implements a simple responsive layout using Flexbox.
The page contains five main sections:

Header

Hero

Content

Sidebar

Footer

The layout changes based on screen width:

Mobile (< 640px): All sections stack vertically.

Desktop (> 640px): Content and Sidebar appear side‑by‑side using a horizontal flex container.

Each section is styled with padding, centered text, and a specific background color as required.
The entire layout is built using <div> elements to satisfy the project constraints
